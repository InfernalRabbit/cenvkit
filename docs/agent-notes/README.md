# Agent notes — durable engineering knowledge

Компактные заметки о внутренностях `cenvkit` для тех, кто меняет код. Здесь то,
чего нет в `--help`: механика compose-go, границы слоёв окружений, ловушки
гейтов и инструментов.

## Зачем это

Репозиторий публикуется без истории внутренней разработки. Технические знания,
накопленные в рабочих журналах и исторических спеках, перенесены сюда в
санитизированном виде — только то, что подтверждается кодом и тестами.

## Иерархия источников истины

1. **Код и тесты** — нормативная истина. Заметка устарела, если расходится с ними.
2. `AGENTS.md` — контракт разработки и верификации (гейты, границы пакетов).
3. `docs/cenvkit.md` (справочник команд) и `docs/guide.md` (пользовательский
   гайд) — поведение для пользователя описывается там, не здесь.
4. `CHANGELOG.md` — что и когда изменилось.
5. Эти заметки — «почему так» и «где подвох».

## Как поддерживать

- **Проверяй по коду перед записью.** Факт должен подтверждаться файлом или
  тестом; если не подтверждается — не пиши.
- **Ссылайся на файлы и символы, а не на номера строк:**
  `internal/engine/flatten.go`, функция `Flatten`. Строки дрейфуют, имена — нет.
- **Одна тема — один файл.** Не дублируй: в остальных местах ставь ссылку.
- **Пиши следствие, а не историю.** «Так нельзя, потому что X» полезнее, чем
  «в прошлом цикле мы это починили».
- **Санитизация обязательна:** никаких абсолютных путей, имён приватных
  репозиториев, почты, внутренних ссылок и названий тикетов. Для примеров —
  `<workspace>`, `<consumer-repo>`, `<repo>`.
- **Синхронность:** меняешь поведение — в том же изменении правишь заметку,
  которая ему противоречит. Добавил файл — добавь строку в таблицу.
- **Объём:** 60–140 строк на файл. Растёт — выноси подраздел, а не абзацы.

## Чего здесь сознательно нет

- Секретов, реальных значений окружений, приватных имён и адресов.
- Процессных инструкций («как вести проект») — это `AGENTS.md`.
- Планов и нереализованных дизайнов: только то, что есть в коде сейчас.
- Пересказа пользовательской документации: вместо этого — ссылки на неё.
